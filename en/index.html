The story behind the course

We lost Fable. We recovered the method.

O Fable was a model with a rare discipline: it thought before acting, checked its own work, narrated its decisions. Then it went offline—and we were left missing way how it worked. Without the model weights, it seemed like that had disappeared along with them.

But it didn’t. Every conversation with an agent leaves a trail: the files .jsonl from each session. You can mine these logs with a script, extract the work discipline — the decision loop (ground → reason → act → observe → re-evaluate → verify → narrate) — and install this method in another model. It doesn't recover the brain; it recovers the manual for how it thought. That shift is the heart of Track 3.
